# StarCraft и Brood War в браузере

[Установить на iPhone](https://superoles-red.github.io/starcraft-mobile-web/?install=iphone) · [Играть в браузере](https://superoles-red.github.io/starcraft-mobile-web/)

Одиночная игра на [KopruluSector](https://github.com/n0madic/KopruluSector/tree/5ff8905b1d0bc6ab52d6563b8ef7b0a75ec40133). Движок на C и SDL3 собран в WebAssembly и рисует через WebGL 2. Его игровая логика воссоздаёт StarCraft. Приложение загружает шесть английских кампаний, музыку, озвучку и 28 роликов. Для первого запуска нужен интернет и современный браузер с WebGL 2.

## Размер и содержимое

Первая загрузка составляет около **292 МБ**. Для установки отведите около **310 МБ** плюс место для сохранений. Публичная библиотека занимает 289 972 981 байт вместе с индексом. После распаковки все 67 игровых архивов побайтно совпадают с предыдущей сборкой. В таблице указаны размеры локальных файлов при десятичном МБ.

| Состав | Размер |
| --- | ---: |
| Ядро игровых данных, интерфейс и эффекты | 49,59 МБ |
| Музыка | 28,88 МБ |
| 64 архива миссий и реплик шести кампаний | 61,15 МБ |
| Все 28 роликов | 156,78 МБ |

Игровые данные публикуются частями до 1 МиБ, с проверкой SHA-256 и сжатием gzip там, где оно даёт выигрыш. Музыка и видео сохранили качество предыдущей сборки. [Измерения качества и размеров](MEDIA.md)

## Установка на iPhone

1. Откройте [ссылку установки](https://superoles-red.github.io/starcraft-mobile-web/?install=iphone) в Safari.
2. Выберите **Поделиться → На экран «Домой»**. Если есть переключатель **«Открывать как веб-приложение»**, включите его и нажмите **Добавить**.
3. Откройте **StarCraft** с новой иконки и оставьте приложение на экране до появления игрового меню. Прогресс показывается на оригинальной заставке. При обрыве соединения загрузка продолжается с уже проверенных частей.

С иконки доступны все шесть кампаний без сети. При следующих запусках с интернетом приложение проверяет обновления. Когда обновление загружено, полностью закройте игру и снова откройте с той же иконки. Настройки, профиль и сохранения хранятся отдельно в IndexedDB. Для теста в Safari и для игры с домашнего экрана iOS может использовать отдельные хранилища.

## Запуск на компьютере

**Публичная сборка** открывается [на GitHub Pages](https://superoles-red.github.io/starcraft-mobile-web/). Для собственных ресурсов доступны [выбор папки repack](https://superoles-red.github.io/starcraft-mobile-web/?folder=1) и [выбор отдельных файлов](https://superoles-red.github.io/starcraft-mobile-web/?files=1).

**На подготовленном Mac** дважды нажмите `run.command`. Откроется локальная игра. Сервер слушает только 127.0.0.1 и по умолчанию читает архивы из `~/Documents/StarCraft Local Data/repack`.

Два адреса локальной версии:

- [Главное меню](http://127.0.0.1:8847/)
- [Первая миссия терранов](http://127.0.0.1:8847/?mission=terran%2Fterran01) для быстрого теста управления.

Другая папка или порт:

```sh
python3 tools/serve.py --pack "/path/to/repack" --port 8847 --open
```

## Подготовка своей копии с двух CD

Импортёр проверяет контрольные суммы английских образов `SC.iso`, `BROODWAR.iso` и накопительного патча `BW-1161.exe`. Все три файла должны лежать в одной папке. Патч читается как архив. Для этого этапа нужны Python 3.10+, `bsdtar` и библиотека StormLib. Для упаковки дополнительно нужны компиляторы C/C++, CMake, Ninja и Git. На macOS подойдут инструменты Command Line Tools и пакеты Homebrew `stormlib cmake ninja`.

```sh
python3 tools/import_discs.py "$HOME/Downloads/StarCraft_BroodWar_distr" "$HOME/Documents/StarCraft Local Data/English1161"
python3 tools/prepare_pack.py
```

Если Python не находит библиотеку StormLib, добавьте к первой команде `--stormlib /path/to/libstorm.dylib`. Импортёр создаёт новую локальную установку, конвертер — соседнюю папку `repack` с архивами игры. Для подготовки достаточно выполнить каждую команду один раз. Существующие папки защищены от перезаписи.

## Изображение и управление

Игра стартует с `--graphics original --font original`. На сенсорном экране остаётся командная панель из игры. Касание своего юнита выделяет его, следующее касание местности отдаёт приказ. Два пальца перемещают камеру и меняют масштаб. На устройствах с основным сенсорным вводом оболочка задаёт лимит отрисовки в 30 кадров/с. Мышь, правая кнопка и клавиатура передаются движку.

## Устройство веб-сборки

Установщик загружает и проверяет библиотеку, затем открывает игру. Движок получает основной архив и читает музыку и карты по мере надобности. Ролики читаются диапазонами из кеша. Стартовая страница, графика установщика, манифест и WebAssembly сохраняются для запуска офлайн.

Каждая версия оболочки привязана к контрольным суммам. Service worker подготавливает обновление отдельно и повторно использует игровые блоки с тем же SHA-256. Действующая версия обслуживает открытые вкладки до их закрытия. Хранилище сохранений имеет постоянное имя.

В `site/library/` находятся индекс и готовые блоки кампаний. Для пересборки библиотеки из локальной папки выполните `python3 tools/package_library.py "/path/to/repack"`. GitHub Actions проверяет состав сайта и контрольные суммы, создаёт версию service worker и публикует результат в GitHub Pages. Для другого статического HTTP-сервера выполните `python3 tools/check_public.py --export output/site` и раздавайте полученную папку через HTTPS или localhost.

Для пересборки кода нужны Git, CMake, Ninja, Python 3 и активированный Emscripten 6.0.12. Скрипт получает закреплённую версию движка и проверяемые upstream-зависимости. Локальные правки выключают дополнительную колонку кнопок для групп на сенсорном экране и восстанавливают переход по оригинальной кнопке Skip Tutorial от Boot Camp к Wasteland.

```sh
tools/build-engine.sh site/engine
python3 tools/check_public.py
```

Условия распространения движка и библиотек находятся в [NOTICES.txt](site/engine/NOTICES.txt). StarCraft и Brood War принадлежат Blizzard Entertainment.

## Что проверено

В установочной сборке проверены загрузка с нуля, чтение видео по диапазону через границу двух частей и запуск миссии Brood War без сети. Для WebKit был выключен сам тестовый HTTP-сервер. В Chromium проверены возобновление после обрыва и ошибки SHA-256, сохранение активной миссии при неудачном обновлении и применение следующей версии после закрытия игры.

На Mac в Chrome пройден путь от создания профиля до Boot Camp и через Skip Tutorial до Wasteland. Тап по морпеху выделяет его, тап по местности отдаёт приказ, два пальца перемещают камеру. Проверены игровой звук, воспроизведение ролика через GitHub Pages и восстановление сохранённого тика и положения камеры после перезагрузки. В настольном WebKit запущена первая миссия зергов Brood War, в Firefox — первая миссия протоссов StarCraft. В мобильном окне Chromium игра перенесла поворот между 844 × 390 и 390 × 844. Полное прохождение всех кампаний и замеры нагрева, частоты кадров и расхода батареи на физическом телефоне остаются отдельными проверками.
