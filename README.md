# StarCraft и Brood War в браузере

[Открыть игру](https://superoles-red.github.io/starcraft-mobile-web/)

Одиночная игра на [KopruluSector](https://github.com/n0madic/KopruluSector/tree/5ff8905b1d0bc6ab52d6563b8ef7b0a75ec40133). Движок на C и SDL3 собран в WebAssembly и рисует через WebGL 2. Его игровая логика воссоздаёт StarCraft. Кампании, графика, звуки, интерфейс и растровые шрифты читаются из локальной копии игры. Для запуска нужны современный браузер с WebGL 2 и игровые ресурсы.

## Запуск

**На подготовленном Mac** дважды нажмите `run.command`. Откроется локальная игра. Сервер слушает только 127.0.0.1 и по умолчанию читает архивы из `~/Documents/StarCraft Local Data/repack`.

**На GitHub Pages** выберите системной кнопкой всю подготовленную папку `repack`. Если браузер вместо папки предлагает отдельные файлы, выберите вместе все `koprulu-*.mpq`. Движок работает в этой вкладке. Браузер читает игровые файлы с устройства и повторно запрашивает выбор при открытии новой сессии. Профиль и сохранения движок хранит в IndexedDB текущего адреса сайта. Для продолжения игры открывайте тот же адрес в том же браузере.

Два адреса локальной версии:

- [Главное меню](http://127.0.0.1:8847/)
- [Первая миссия терранов](http://127.0.0.1:8847/?mission=terran%2Fterran01) для быстрого теста управления.

Другая папка или порт:

```sh
python3 tools/serve.py --pack "/path/to/repack" --port 8847 --open
```

## Изображение и управление

Игра стартует с `--graphics original --font original`. На сенсорном экране остаётся командная панель из игры. Касание своего юнита выделяет его, следующее касание местности отдаёт приказ. Два пальца перемещают камеру и меняют масштаб. На устройствах с основным сенсорным вводом оболочка задаёт лимит отрисовки в 30 кадров/с. Мышь, правая кнопка и клавиатура передаются движку.

## Устройство веб-сборки

Для старта оболочка помещает в память основной архив. Движок запрашивает музыку и архивы миссий по мере надобности. Видео читает диапазонами байтов. В локальной версии их отдаёт Python-сервер. На Pages service worker берёт соответствующие диапазоны из файлов в выбранной папке этой вкладки. Веб-сборка рассчитана на одиночную игру.

В каталоге `site/` находятся только браузерный код, модуль WebAssembly и лицензии. GitHub Actions проверяет список файлов перед публикацией.

Для пересборки кода нужны Git, CMake, Ninja, Python 3 и активированный Emscripten 6.0.12. Скрипт получает закреплённую версию движка и проверяемые upstream-зависимости. Локальная правка выключает дополнительную колонку кнопок для групп на сенсорном экране.

```sh
tools/build-engine.sh site/engine
python3 tools/check_public.py
```

Условия распространения движка и библиотек находятся в [NOTICES.txt](site/engine/NOTICES.txt). StarCraft и Brood War принадлежат Blizzard Entertainment.
